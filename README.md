# TaskFlow – Full Stack Todo List Application

TaskFlow is a full-stack Todo List application that helps users organize their daily tasks, manage productivity, and track task completion. It provides secure authentication, task management, weather information, and social login integration.

## 🚀 Features

- User Registration and Login
- JWT-based Authentication
- Password Hashing using bcrypt
- Google Login Integration
- Facebook Login Integration
- Add New Tasks
- Edit Existing Tasks
- Delete Tasks
- Mark Tasks as Completed or Pending
- Search Tasks
- Filter Tasks (All, Pending, Completed)
- User-specific Tasks
- Weather Information
- Responsive User Interface
